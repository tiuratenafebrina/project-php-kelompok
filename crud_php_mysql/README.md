# Project PHP Kelompok

Aplikasi CRUD data mahasiswa (PHP dan MySQL) untuk Praktikum Pengembangan Aplikasi Web Modul 6.

## Anggota dan Pembagian Tugas
- Tiur Atenafebrina: dasar project (generate, connection, index), login, logout
- Davina Christy Welyanti: student_view, student_add
- Ecber Layuk: student_edit, student_delete
- Gizela Carla A.T.: belajar_form (registration, registration_process)

## Cara Menjalankan
1. Nyalakan Apache dan MySQL di XAMPP.
2. Clone repository ini ke folder htdocs.
3. Buka crud_php_mysql/generate.php sekali untuk membuat database.
4. Buka crud_php_mysql/login.php dan login memakai akun admin.
